# novanest-admin-web

NovaNest Admin Panel — React + Vite + Tailwind CSS

## Overview

Internal admin panel for managing the NovaNest real estate platform.

## Features

- Dashboard with business overview
- Projects, Buildings, Floors, Apartments management
- Customer account creation and management
- Apartment assignments
- Customer updates and document uploads
- Inquiry management
- News & Insights articles
- Careers and job applications

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- TanStack Query
- React Router v6
- React Hook Form
- Axios
- Lucide React

## Getting Started

```bash
npm install
npm run dev       # runs on http://localhost:3001
```

## Requirements

The NovaNest backend must be running on port 5000.
See: https://github.com/dulajweligaththa08/novanest-backend-web
